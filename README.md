# Python Foundations for Scientific Computing

AIMS Senegal programming course notes, practice exercises and daily learning reports.

## Contents

The notebooks practise Python variables, data types, collections, control flow, functions and standard-library tools. The repository also contains an earlier airline route-planning notebook.

For the dedicated applied project, see [African airline route planning](https://github.com/Thierrykuatemabap/Optimal_Airline_Route_Planning_final_project).

## How to use

Install Python and a Jupyter notebook interface, open an exercise notebook and work through its cells. Introductory notebooks intentionally include examples of invalid syntax and runtime errors; treat those cells as part of the lesson.

The airline notebook additionally requires scientific/data libraries and external inputs. Its dedicated repository documents the project and input dependencies.
